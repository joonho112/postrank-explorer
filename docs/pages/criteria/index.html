Multiple criteria

The same units can rank differently across criteria. A common report assigns one grade per unit and evaluates those grades on every criterion. A domain profile gives each domain its own column.

One column

Common grades

One ordered grade column, evaluated across criteria.

Explore 14 apps ↓

One column per domain

Domain profiles

Separate grade columns preserve each domain's directions.

Explore P.1–P.5 ↓

Grade 1 is highest within each column. A profile reports each domain's order separately.

Common grades

The same grade column states a direction on every criterion. Two scores shows what happens when those directions conflict. Criterion-specific costs compares each criterion’s risk under the shared grades with its own minimum. Withheld comparisons traces why individual directions are left unranked.
